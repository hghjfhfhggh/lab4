# Задание

Данное задание направлено на закрепление принципов работы со стеком и функциями
ассемблера для платформы x86-64.

Разработать программу реализующую алгоритм сортировки Quick Sort. Программа
получает на вход количество элементов массива и сами элементы и должна выводить
массив, отсортированный по возрастанию. Алгоритм сортировки должен быть
реализован на ассемблере, код чтения выходных данных, выделения памяти и вывода
на языке Си.

**Пример:**

Ввод:

```
14
54 38 74 22 19 66 16 90 82 31 21 88 27 13
```

Вывод:

```
13 16 19 21 22 27 31 38 54 66 74 82 88 90
```


## Требования к операционной системе

Заданием необходимо выполнять в операционной системе на базе Linux с
установленными компилятораями `nasm` и `gcc`.


## Порядок работы

В файле `main.nasm` написан шаблонный код на яызке ассемблера для компилятора
`nasm`. 

В коде содержатся комментарии с пояснениями.

Для отладки кода перед отправкой необходимо выполнить команду:

```shell
python3 main.py
```

Данная команда выполнит сборку и проверку результата.
